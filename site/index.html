Session folders, a colourful terminal, an SFTP/SCP file explorer and a server status bar. All in one window, no sign-up.

Сессии и папки

Sessions and folders

Сколько угодно сессий, папки любой вложенности, перетаскивание мышью. Вход по паролю или по ключу. Импорт из MobaXterm, PuTTY и ~/.ssh/config.

Unlimited sessions, nested folders, drag and drop. Password or key login. Import from MobaXterm, PuTTY and ~/.ssh/config.

Пароли под замком

Passwords locked away

Всё хранится в одном файле, зашифрованном мастер-паролем (Argon2id и AES-256-GCM). Ключи серверов проверяются как в OpenSSH.

Everything lives in one file encrypted with a master password (Argon2id and AES-256-GCM). Server keys are verified like in OpenSSH.

Цветной терминал

Colourful terminal

Подсветка ошибок, предупреждений, адресов и дат по вашим правилам. Подсветка кода в vim и nano. Выделил мышью — уже в буфере, правая кнопка вставляет.

Highlighting of errors, warnings, addresses and dates by your own rules. Code highlighting in vim and nano. Select to copy, right-click to paste.

Проводник SFTP / SCP

SFTP / SCP explorer

Файлы сервера рядом с терминалом, панель следует за каталогом шелла. Загрузка, скачивание, права доступа, вопрос при совпадении имён.

Server files next to the terminal; the panel follows the shell's directory. Upload, download, permissions, a prompt on name conflicts.

Состояние сервера

Server status

CPU, память, скорость сети, аптайм и заполнение дисков внизу вкладки. На сервер ничего не устанавливается.

CPU, memory, network speed, uptime and disk usage at the bottom of the tab. Nothing is installed on the server.

Несколько сессий сразу

Several sessions at once

Окно можно разделить на две или четыре области, в каждой своя сессия. Интерфейс на русском и английском.

Split the window into two or four panes, each with its own session. The interface is available in Russian and English.
